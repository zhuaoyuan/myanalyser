## 1. 数据预备（prep_data_workflow）

**脚本**：`myanalyser/tools/v2/prep_data_workflow.py`

**作用**：仅抓取全量原始 L1 数据，不做筛选（宽存）。为后续 `run_full_pipeline` 提供基金购买列表及辅助数据。

### 处理逻辑

1. **x - 基金购买列表**：获取全体可购买基金（调用 `run_step1_purchase`），或复用已有 `--purchase-csv`
2. **a - 持有人比例**：按 `purchase` 抓取持有人结构全历史；传入 `--cyrjg-csv` 则直接复用
3. **b - 基金规模**：按 `purchase` 抓取规模全历史；传入 `--gmbd-csv` 则增量合并
4. **c - 基金费率**：按 `purchase` 抓取费率全历史；传入 `--fee-csv` 则增量合并
5. **e - 基金详情**：按 `purchase` 抓取基金概况；传入 `--overview-csv` 则增量

### 命令样例

```bash
cd /Users/zhuaoyuan/cursor-workspace/finance
source myanalyser/.venv312/bin/activate

python myanalyser/tools/v2/prep_data_workflow.py \
  --work-dir myanalyser/tmp/prep_work_v2 \
  --purchase-csv myanalyser/tmp/1_refilter/prep_work/fund_purchase.csv \
  --cyrjg-csv finance-runs/run_20260310_191534/data/versions/20260310_191534/fund_etl/cyrjg_out.csv \
  --gmbd-csv myanalyser/tmp/1_refilter/prep_work/fund_gmbd.csv \
  --fee-csv myanalyser/tmp/1_refilter/prep_work/fund_fee_structured.csv \
  --overview-csv myanalyser/tmp/1_refilter/prep_work/fund_overview.csv \
  --delay 0

# 全量从零开始（不传入已有 CSV）：
python myanalyser/tools/v2/prep_data_workflow.py \
  --work-dir myanalyser/tmp/prep_work_v2 \
  --delay 0.3
```

### 产物列表

产出到 `--work-dir`（默认 `myanalyser/tmp/prep_work_v2`），固定文件名：

| 文件 | 说明 |
|------|------|
| `fund_purchase.csv` | 基金购买列表 |
| `fund_cyrjg.csv` | 持有人比例全历史 |
| `fund_gmbd.csv` | 基金规模全历史 |
| `fund_fee_structured.csv` | 基金费率结构化 |
| `fund_overview.csv` | 基金详情 |

## 2. 数据预过滤（prep_filter，可跳过）

**脚本**：`myanalyser/tools/prep/prep_filter.py`

**作用**：在特定情况下对基金池做预筛选，减小主流程（`run_full_pipeline`）处理数据量。**可跳过**，主流程通常直接使用步骤 1 的 `fund_purchase.csv`。

### 处理逻辑

基于日期、规模、费率和成立时间等条件，从 `fund_purchase` 筛选出符合条件的基金子集，输出为缩减后的购买列表。内部调用 `filter_fund_fee_by_holding` 做费率分类，再与规模、成立日期等规则取交。

### 命令样例

```bash
python myanalyser/tools/prep/prep_filter.py \
  --date 2021-01-01 \
  -o myanalyser/tmp/prep_filtered/fund_purchase_filtered.csv \
  --work-dir myanalyser/tmp/prep_filter_work \
  --purchase-csv myanalyser/tmp/prep_work_v2/fund_purchase.csv \
  --gmbd-csv myanalyser/tmp/prep_work_v2/fund_gmbd.csv \
  --fee-csv myanalyser/tmp/prep_work_v2/fund_fee_structured.csv \
  --overview-csv myanalyser/tmp/prep_work_v2/fund_overview.csv \
  --delay 0.1
```

### 产物列表

| 文件 | 说明 |
|------|------|
| `-o` 指定路径 | 筛选后的基金购买列表（供 run_full_pipeline 使用） |
| `work-dir/fund_fee_filtered.csv` | 费率分类结果（中间产物） |

## 3. 正式数据抓取（run_full_pipeline）

**脚本**：`myanalyser/tools/v2/run_full_pipeline.sh`

**作用**：L1 全流程：基金 ETL（step1~step7）+ 复权净值计算。不含 integrity/compare/filter/scoreboard/backtest。

### 处理逻辑

1. **step1 - 基金购买**：使用本地 `fund_purchase.csv`（`@path` 模式）或执行 `fund_etl step1` 拉取
2. **step2 - fund_etl**：verify + step2~step7（overview、净值、分红、拆分、人事、累计收益率）
3. **step3 - 复权净值**：`adjusted_nav_tool` 计算复权净值

支持 checkpoint 断点续跑；可选 `BONUS_SPLIT_REVISE_ROOT` 指定分红/拆分校对目录。

### 命令样例

```bash
cd /Users/zhuaoyuan/cursor-workspace/finance
source myanalyser/.venv312/bin/activate

# 使用步骤 1 的 fund_purchase：
bash myanalyser/tools/v2/run_full_pipeline.sh @myanalyser/tmp/prep_work_v2/fund_purchase.csv

# 使用预过滤后的购买列表：
bash myanalyser/tools/v2/run_full_pipeline.sh @myanalyser/tmp/prep_filtered/fund_purchase_filtered.csv

# 全量抓取（不传 purchase，内部执行 step1）：
bash myanalyser/tools/v2/run_full_pipeline.sh

# 指定 RUN_ID、ETL 并发等：
RUN_ID=20260319_120000_full_run_v2 \
ETL_MAX_WORKERS=8 \
ETL_PROGRESS_INTERVAL=5.0 \
bash myanalyser/tools/v2/run_full_pipeline.sh @myanalyser/tmp/prep_work_v2/fund_purchase.csv
```

### 产物列表

|-----------|------|

| `fund_etl/fund_overview.csv` | 基金概况 |
| `fund_etl/fund_nav_by_code/` | 原始净值（按基金代码分文件） |

### 4.3 自定义策略回测（multi_t_backtest）

**脚本**：`myanalyser/tools/v2/multi_t_backtest.py`

**作用**：在多 T 日上执行策略回测。每个 T 日：prep_eligible → filter → scoreboard → 回测。支持 `--t-list` 或 `--t-start`/`--t-end`/`--t-step`。

### 处理逻辑

1. 构建 T 日列表（按交易日历）
2. 对每个 T：  
   - compare/integrity 窗口缓存（延伸至 `end_extended = T + hold_days`）  
   - prep_eligible：费率、规模、成立日期、人事排除  
   - filter：数据质量过滤  
   - scoreboard：评分榜单  
   - 回测：从 T 日买入，持仓 `hold_days` 个交易日
3. 汇总各 T 结果到 `multi_summary.csv`、`multi_summary_agg.csv`

### 命令样例

**方式一：指定 T 列表**

```bash
python myanalyser/tools/v2/multi_t_backtest.py \
  --run-id "20260319_120000_full_run_v2" \
  --ruleset-version "20260319_v1" \
  --t-list "2023-01-03,2023-07-03,2024-01-02,2024-07-01" \
  --trading-calendar-csv "myanalyser/data/common/trade_dates.csv" \
  --prep-work-dir "myanalyser/tmp/prep_work_v2" \
  --lookback-years 3 \
  --hold-days 21 \
  --strategy "low_risk_debt_most_stable" \
  --max-funds 5000 \
  --rebalance 0 \
  --top-n 5 \
  --warmup 0 \
  --initial-cash 100000
```

**方式二：T 区间 + 步长**

```bash
python myanalyser/tools/v2/multi_t_backtest.py \
  --run-id "20260319_120000_full_run_v2" \
  --ruleset-version "20260319_v2" \
  --t-start 2010-01-01 \
  --t-end 2026-03-01 \
  --t-step 25 \
  --trading-calendar-csv "myanalyser/data/common/trade_dates.csv" \
  --prep-work-dir "myanalyser/tmp/prep_work_v2" \
  --lookback-years 3 \
  --hold-days 42 \
  --strategy "low_risk_debt_most_stable" \
  --max-funds 5000 \
  --rebalance 0 \
  --top-n 5 \
  --warmup 0 \
  --initial-cash 100000
```

**可选：限定基金类型**

```bash
python myanalyser/tools/v2/multi_t_backtest.py \
  --run-id "..." \
  --ruleset-version "..." \
  --fund-types "A类730天" "C类30天" \
  ...（其余参数同上）
```

### 产物列表

产出到 `artifacts/backtest_multi/{run_id}/{ruleset_version}/`：

| 文件/目录 | 说明 |
|-----------|------|
| `multi_summary.csv` | 各 T 日回测汇总（as_of_date, metrics 等） |
| `multi_summary_agg.csv` | 跨 T 的聚合统计（mean/median/std/win_rate 等） |
| `{as_of_date}/` | 每个 T 日的单次回测产物 |
| `{as_of_date}/summary.csv` | 单 T 汇总 |
| `{as_of_date}/period_detail.csv` | 每期调仓明细 |
| `{as_of_date}/equity_curve.csv` | 净值曲线 |
| `{as_of_date}/orders.csv` | 订单明细 |

| `{as_of_date}/backtest_report.md` | 文本报告 |

## 5. 结果展示（compare_backtest_curves）
