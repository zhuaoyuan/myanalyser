# v2 日期与区间协议约定

**文档位置**: `myanalyser/docs/参考/v2日期与区间协议约定.md`  
**适用范围**: v2 系列全流程（multi_t_backtest、verify_filter_flow_report、prep_eligible、compare、integrity、filter 等）  
**更新**: 2026-03-16

---

## 1. 交易日 vs 自然日

| 参数/环节 | 口径 | 说明 | 代码入口 |
|----------|------|------|----------|
| `hold_days` | **交易日** | 持仓期按交易日历推进 | `backtest_helpers.compute_end_extended_str` |
| `--t-step` | **交易日** | 在交易日历上步进 | `multi_t_backtest._build_t_list` |
| `lookback-years` | **交易日** | 1 年 = 243 个交易日（A 股口径） | `backtest_helpers.compute_start_from_lookback` |
| Integrity / Compare 区间 | **交易日** | `load_trade_days` 筛选 | `check_trade_day_data_integrity` |
| 成立+2年、end-1年（人事） | **自然日** | `pd.DateOffset`，业务语义 | `prep_eligible_window` |

### 1.1 常量

- **1 年 = 243 交易日**：与 `fund_metrics_core.WindowConfig.trading_days_per_year` 一致，A 股近 10 年平均约 242–244 天。

---

## 2. 开闭区间

| 场景 | 约定 | 实现 |
|------|------|------|
| 日期区间 [start, end] | **双闭** | `>= start` 且 `<= end` |
| 费率阶梯（金额/持仓期限） | **左闭右开 [a,b)** | 文档 `fund_fee_空值成因分析_20260313`；边界值归属下一档 |
| 回测持仓期 [T, sell_date] | 含头含尾 | `end_index = t_index + hold_days` |

---

## 3. 流程环节协议

| 环节 | 区间 | 说明 |
|------|------|------|
| prep_eligible 窗口 | [start_date, end_date] 双闭 | end_date 为 T 日，不延伸 |
| Compare / Integrity | [start_date, end_extended] 双闭 | end_extended = T + hold_days（交易日） |
| filter | [start_date, end_extended] 双闭 | 与 Compare/Integrity 一致 |
| backtest | [T, T+hold_days 日] | T 日买入，hold_days 个交易日后卖出 |
