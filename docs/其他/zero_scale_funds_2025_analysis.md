# 2025 年规模归零基金分析报告

基于 `fund_gmbd.csv` 数据，筛选条件：
- **2025 年**某季末规模 ≤ 0.001 亿元（视为归零）
- **此前**任一报告期规模曾 > 2 亿元

## 一、筛选结果汇总

- **符合条件基金数**：157 只
- **净值目录中实际有净值文件的数量**：约 4 只（前 50 只中），说明多数归零基金在 `fund_adjusted_nav_by_code` 中无单独净值文件（可能已清盘或未纳入该 run 的净值抓取范围）

## 三、主要结论

1. **净值仍在更新**：上述 4 只基金净值数据持续到 2026 年 3 月，说明基金仍在运作，2025 年规模为 0 更可能为**某季末报告披露的暂时状态**，而非永久清盘。
2. **规模波动大**：多数在 2025 年某季末归零后，当年度内又有回升，可能与申购赎回、转型、合并等有关。
3. **净值数据覆盖有限**：`fund_adjusted_nav_by_code` 中仅有约 5,109 只基金的净值文件，157 只归零基金中多数无对应净值文件，可能为清盘基金或未被纳入该 run 的净值抓取清单。
