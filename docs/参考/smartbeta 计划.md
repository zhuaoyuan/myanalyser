## 一、选择哪（几）种 Smart Beta 进行投资？

### 核心思路：因子互补 + A 股适配 + 长期有效性验证

A 股市场经过学术研究和实战验证，长期有效的 Smart Beta 因子主要有：

| 因子 | A 股有效性 | 与你现有配置的关系 | 建议优先级 |
|------|-----------|-------------------|-----------|
| **红利（Dividend）** | 强，尤其低利率周期 | 你已持有 ~68w 红利类，有基础 | 高 |
| **红利低波（Dividend Low Vol）** | 强，防御性优秀 | 已持有 18w 红利低波ETF | 高 |
| **质量（Quality）** | 中强，ROE/盈利稳定性 | 你看板中"中证红利质量ETF"已涉及 | 中高 |
| **价值（Value）** | 周期性强，均值回归 | 与红利有一定重叠 | 中 |
| **等权/基本面加权** | 中，降低集中度风险 | 补充市值加权的偏差 | 中 |
| **动量（Momentum）** | A 股短期有效、长期需择时 | 你已规划单独 5% 动量策略 | 低（已独立） |

**推荐组合：红利 + 红利低波 + 质量**，这三个因子在 A 股长期有效性最强，且互相之间相关性适中，能形成有效的因子分散。

| **持有人结构** | 机构占比 | 参考，非决定性 |
| **流动性** | 日均成交额 | > 1000 万 |

## 三、多只基金如何配比？

### 推荐方法：风险平价（Risk Parity）+ 因子暴露约束

**第一层：因子层面配比**

```
红利因子 : 红利低波因子 : 质量因子 = 40% : 35% : 25%
```

逻辑：红利和红利低波是 A 股长期最稳定的 alpha 来源；质量因子作为补充分散。

**第二层：同因子内基金配比**

如果同一因子下选了多只基金（例如红利因子下选了"红利ETF"和"红利低波ETF"），可以用 **等权** 或 **最小方差** 来分配。

### 量化实现

你的 `multi_t_backtest.py` 和 `chain_multi_t_backtest.py` 已经支持组合回测，可以扩展为支持不同配比方案的对比：

```python
# 方案对比矩阵
allocation_schemes = {
    "equal_weight":    {"红利": 0.33, "红利低波": 0.33, "质量": 0.34},
    "risk_parity":     {"红利": 0.40, "红利低波": 0.35, "质量": 0.25},
    "max_sharpe":      None,  # 由优化器计算

```

配合 `benchmark_portfolio_backtest.py` 做基准组合对照。

## 四、建仓策略

### 推荐：分批建仓 + 估值辅助

鉴于你这块的总投入可能在几十万到上百万级别，建议：

| 策略 | 适用场景 | 具体方案 |
|------|---------|---------|
| **等额分批** | 默认策略 | 将总金额分 6~12 期，每 2 周或每月买入一批 |
| **估值加权** | 对估值敏感时 | PE/PB 分位 < 30% 时加大单批金额（1.5x），> 70% 时减少（0.5x） |
| **波动率触发** | 市场剧烈波动时 | 短期跌幅 > 5% 时触发额外加仓批次 |

## 五、调仓策略

### 推荐：低频定期 + 触发式相结合

| 机制 | 频率/条件 | 操作 |
|------|----------|------|
| **定期再平衡** | 每半年（6月/12月） | 恢复至目标配比 |
| **阈值触发** | 单因子偏离目标 > 5% | 触发再平衡 |
| **基金替换** | 年度审视 | 跟踪误差恶化、规模骤降、费率变化时替换 |
| **因子轮动** | 不建议 | Smart Beta 长期持有是核心，频繁轮动反而损耗 |

### 关键原则

- **低换手**：Smart Beta 的核心优势是低成本长期暴露因子溢价，频繁调仓会侵蚀收益
- **再平衡而非择时**：只做回到目标权重的操作，不做主观判断
- **年度基金体检**：用你现有的 scoreboard 流水线对持仓基金做年度评估

## 七、看板设计

### 设计原则

> **信息分层 + 行动导向 + 去噪降焦虑**

一个好的长期投资看板应该**帮你少看、少动**，而不是刺激你频繁操作。

### 看板结构建议

```
┌─────────────────────────────────────────────────┐
│  📋 每日一屏（Daily Glance）                      │
│  ─────────────────────────────────────────────── │
│  组合净值: ¥XXX.XX (日+0.12% / 年+8.3%)          │
│  今日状态: ✅ 正常 / ⚠️ 需关注 / 🔴 需行动        │
│  待办事项: 无 / "距下次再平衡还有 23 天"            │
├─────────────────────────────────────────────────┤
│  📊 组合健康度（Weekly Review）                    │
│  ─────────────────────────────────────────────── │
│  因子配比偏离度: 红利 +1.2% | 低波 -0.8% | 质量 -0.4%│
│  滚动1年夏普: 0.82 (健康)                          │
│  最大回撤: -4.3% (远离警戒线)                       │
│  vs 沪深300: +3.2% (跑赢)                          │
├─────────────────────────────────────────────────┤
│  🔔 告警区（仅有异常时显示）                        │
│  ─────────────────────────────────────────────── │
│  [空 = 一切正常，不显示任何内容]                     │
│  或: ⚠️ 红利因子偏离 5.3%，建议下次定投时调整        │
├─────────────────────────────────────────────────┤
│  📈 长期视角（Monthly，默认折叠）                   │
│  ─────────────────────────────────────────────── │
│  组合净值走势图（vs 沪深300）                       │
│  各因子累计收益对比                                 │
│  年度收益日历热力图                                 │
│  再平衡历史记录                                    │
└─────────────────────────────────────────────────┘
```

### 心态管理的设计要点

1. **默认显示最少信息**：日常只看"今日状态"一行，绿灯就关掉
2. **用相对指标替代绝对盈亏**：显示"年化收益率"而非"赚了/亏了多少钱"，降低锚定效应
3. **弱化短期波动**：日收益率用小字体，年化/滚动收益用大字体
4. **行动导向的告警**：不是"你亏了 3%"，而是"一切正常，无需操作"或"偏离度达阈值，建议下次定投时微调"
5. **加入长期锚定**：显示"持有 XXX 天"、"距上次操作 XX 天"，强化长期持有心态

### 技术实现路径

你现有的 `gen_scoreboard_html.py` 已经能生成 ECharts 静态 HTML。可以扩展为一个 **Smart Beta 看板生成器**，核心模块：

```
smart_beta_dashboard/
├── data_collector.py      # 每日从 AkShare 拉最新净值
├── portfolio_tracker.py   # 持仓记录 + 组合净值计算
├── risk_monitor.py        # 风控指标计算 + 告警判定
├── rebalance_engine.py    # 再平衡建议生成
└── gen_dashboard_html.py  # 静态 HTML 看板（ECharts/Plotly）
```

运行方式：每天定时执行一次（cron 或手动），生成一个静态 HTML 文件，浏览器打开即可。
