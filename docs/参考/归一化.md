对主次目标归一化时，是使用预设静态的参考区间，还是依据所有参与对比的基金的指标值的上下界做线性归一化？

这是一个非常核心的工程实践问题。在量化系统（如你的 `myanalyser`）中，选择**静态区间**还是**动态上下界**，本质上是在选择**“绝对标准”**与**“相对优劣”**。

直接给结论：**建议采用“动态上下界”为主，同时引入“静态基准值”作为边界修正的混合模式。**

以下是两种方式的深度对比及实战建议：

---

### 1. 动态归一化 (Min-Max Scaling based on Candidates)

依据当前所有参与对比的基金指标的最大值 ($S_{max}$) 和最小值 ($S_{min}$) 进行线性映射。

* **计算公式：**

$$S_{norm} = \frac{S - S_{min}}{S_{max} - S_{min}}$$


* **优点：** 灵敏度极高。它能放大候选池中细微的差异，在“矮子里拔将军”时非常有效。
* **缺点：** * **均值漂移：** 如果某次筛选的所有基金都很烂（例如全市场大跌），最烂的那个是 0 分，最好的那个依然是 1 分，这会给你“这个组合很完美”的错觉。
* **离群值干扰：** 如果出现一个指标极其夸张的“妖基”，会导致其他正常优秀的基金分值全部被压缩在 0.1 左右，失去区分度。



### 2. 静态归一化 (Preset Static Range)

使用你预设的行业经验值或历史统计值作为上下界。

* **优点：** 结果具有**跨时间的可比性**。今天的 0.8 分和明年的 0.8 分代表同样的优秀程度。
* **缺点：** * **钝化：** 在极端行情下（如全市场都在暴涨或暴跌），可能所有基金的得分都挤在 0.9 以上或 0.1 以下，无法选出最优。

---

### 3. 推荐方案：带有“保底与封顶”的动态归一化

为了兼顾两者的优点，我在实战中通常推荐**“动态提取 + 静态裁剪”**。

#### **具体逻辑：**

1. **动态提取：** 获取当前对比池的 $S_{min}$ 和 $S_{max}$。
2. **静态修正：** 引入一套“行业基准”。
* 例如：计算卡玛比率时，如果池子里最优秀的只有 1.2，但你认为真正的优秀必须达到 2.0。那么你的映射上限应取 $\max(S_{max}, 2.0)$。


3. **异常值处理（Winzorize）：** 对原始数据进行 5% 的缩尾处理，防止“妖基”拉高天花板。

#### **代码实现思路（Python 伪代码）：**

```python
def robust_normalize(series, preset_min=0, preset_max=None):
    # 1. 缩尾处理，去掉前2%和后2%的极端异常值
    low = series.quantile(0.02)
    high = series.quantile(0.98)
    clipped = series.clip(low, high)
    
    # 2. 结合静态边界
    # 注意：preset_min 宜 <= clipped 最小值，否则 actual_min 过小可能导致归一化分母异常
    actual_min = min(clipped.min(), preset_min)
    # 如果 preset_max 为 None，则完全动态；如果有值，则作为参考上限
    actual_max = max(clipped.max(), preset_max) if preset_max else clipped.max()
    denom = actual_max - actual_min
    if denom <= 0:
        return (clipped - actual_min)  # 或根据业务做兜底
    return (clipped - actual_min) / denom

```

### 4. 针对不同指标的策略建议

| 指标类型 | 推荐归一化方式 | 静态参考值 (锚点) |
| --- | --- | --- |
| **卡玛/夏普** | **动态 + 静态上限** | 上限设为 3.0 (达到此值即为满分，再高也没意义) |
| **年化收益** | **动态 + 静态下限** | 下限设为 3% (跑不赢货币基金的按 0 分处理) |
| **修复天数** | **动态 + 静态上限** | 上限设为 250天 (超过一年不创高点的视为 0 分) |

### 总结

在 `myanalyser` 中，建议你：

1. **硬约束**用静态值（死标准）。
2. **主次目标**用动态归一化（选最强）。
3. **分值修正**用静态锚点（防错觉）。

这样做出来的排名，既能帮你选出当前的“最优解”，又能通过分值的绝对高低提醒你：**“虽然它是现在最好的，但它的绝对分数很低，可能现在不是入场的好时机。”**

你想为你的归一化逻辑增加一个“市场平均水平”作为 0.5 分的锚点吗？这样可以更直观地看到超额表现。
