开头

判断量化策略是过拟合还是真有效，是实盘前最核心的关卡。 很多回测收益爆表的策略，实盘亏到怀疑人生，基本都是过拟合。 今天我就把行业通用的验证方法说透。

观点1：先看样本外测试的收益稳定性

核心逻辑是：过拟合的策略只在回测样本里有效，换样本就失效。 《主动投资组合管理》提到：样本外夏普比率不足回测的30%，大概率是过拟合。

样本外测试不能随便切时间点，要避开刻意选的行情段。 比如你回测用了2018-2022年的A股数据，样本外就选2023年至今。 别手动调整参数凑样本外收益，那等于又做了一次拟合。 宽投2023年量化策略报告显示：87%的回测夏普>2的策略，样本外夏普<0.5。

我之前测过一个小盘股反转策略，回测夏普2.8，样本外只有0.3。 仔细看才发现，回测时刚好踩中了2021年小盘股行情的风口。 样本外刚好遇到小盘风格切换，直接就露馅了。 你可以用聚宽的样本外检测工具自动拆分测试集，避免手动操作的偏差。

观点2：做参数敏感性测试，看收益会不会陡变

核心逻辑是：真有效的策略对参数不敏感，微调参数收益不会大跳水。 世界顶级对冲基金AQR的研报明确：参数变动±20%，收益回撤超过30%就是过拟合。

比如你做均线策略，用5日均线和7日均线，收益差一半肯定不对。 真有效的趋势策略，参数在合理范围内变动，收益应该是平滑波动的。 我见过很多新手把参数调到个位级，回测收益特别高，实盘直接亏。 优矿2024年量化策略调研显示：62%的个人开发者的策略，参数变动10%收益就腰斩。

之前有个朋友做了个期货高频策略，回测年化150%，参数是固定的3秒撮合。 我让他把参数改成2秒和4秒，收益直接掉到年化20%，最大回撤到40%。 明显就是把参数刚好拟合到了历史的成交缝隙里，实盘根本不可能复制。 你可以参考Backtrader的参数优化文档做全参数扫描，看收益分布。

观点3：做压力测试，极端行情下不失效才是真有效

核心逻辑是：过拟合的策略只会在常规行情赚钱，极端行情直接崩。 美联储2022年金融稳定报告提到：72%的量化回撤事件，源于策略未通过压力测试。

你要专门把历史上的极端行情摘出来单独测，比如2020年美股熔断、2015年A股股灾、2022年原油负价。 如果策略在这些时间段出现远超平均的回撤，甚至直接穿仓，肯定是过拟合。 国内头部量化九坤投资的内部验证标准里，极端行情回撤不得超过历史最大回撤的1.5倍。

我之前测过一个套利策略，普通行情下年化30%，最大回撤3%，看起来特别稳。 放到2022年4月A股跌停潮的行情里，单次回撤直接到15%，因为当时流动性枯竭，价差根本收不回来。 这种策略平时赚点小钱，遇到极端行情一次就把利润吐完。 你可以用TuShare的极端行情数据集快速获取历史极端行情片段，针对性测试。

观点4：看策略逻辑能不能落地，有没有真实盈利来源

核心逻辑是：真有效的策略一定能说清赚的是谁的钱，过拟合只有数字没有逻辑。 量化投资大师西蒙斯在公开演讲中说：没有逻辑支撑的高收益策略，我一律否决。 别信什么"黑箱策略""深度学习自动挖掘的策略"，逻辑说不通的大概率是拟合了噪声。 比如你赚的是对手方犯错的钱，还是流动性补偿的钱，还是信息差的钱，总得占一样。 《量化交易实战》里统计：逻辑无法解释的策略，实盘存活率不足5%。

之前看到有人做了个"农历节气择时策略"，回测年化40%，听起来特别玄学。 仔细看其实是刚好拟合了A股过去几年的春季行情、国庆行情的时间点，本质就是把日期和行情硬凑到一起。 根本没有任何逻辑支撑，实盘用的话亏是迟早的事。 你可以参考QuantStart的策略逻辑验证框架，一步步拆解策略的盈利来源。

个人见解

我做量化10年，见过太多人沉迷回测的高收益，不愿意承认自己过拟合。 其实验证的本质就是"故意刁难"你的策略，想方设法让它失效。 如果各种测试都扛过去了，那大概率是真能赚钱的好策略。 别舍不得砍过拟合的策略，实盘亏的钱可比你花在测试上的时间成本贵多了。

总结

判断过拟合其实就是四步：样本外测试、参数敏感性测试、极端行情压力测试、逻辑验证。 四步都通过的策略，实盘收益的确定性会高很多。
