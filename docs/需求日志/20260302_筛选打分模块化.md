# 需求日志：筛选与打分模块化

**日期**：20260302  
**需求描述**：筛选和打分功能模块化，入口脚本支持可扩展的过滤策略与算分策略。

## 需求澄清

- **输入**：
  1. 基金榜单 CSV（形如 fund_scoreboard_*.csv）
  2. 0~多个 Python 过滤脚本（无状态，row -> (是否过滤, 原因)）
  3. 1 个 Python 算分脚本（无状态，df -> df 带综合得分及计算过程列）
  4. 工作目录

- **产物**：
  - 中间：filter_result.csv（原表 + 各策略过滤结果列）
  - 最终：scored_result.csv（剔除被过滤行 + 综合得分、计算过程列）

- **样例策略**：
  - 过滤：最稳健原则（9 条规则，均需满足）
  - 算分：低风险偏债得分（同 compute_fund_composite_score 逻辑）

## 设计与实现

- 入口：`src/filter_score/filter_and_score_main.py`，模板方法控制主流程
- 策略接口：`base.py` 中 `load_filter_strategy` / `load_score_strategy` 通过 `importlib` 加载外部脚本
- 过滤脚本约定：`STRATEGY_NAME`、`filter_one(row) -> (bool, str)`
- 算分脚本约定：`STRATEGY_NAME`、`compute_score(df) -> df`
- 内置样例：`filters/most_stable.py`、`scores/low_risk_debt.py`
