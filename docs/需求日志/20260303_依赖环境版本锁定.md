# 需求日志：依赖与环境版本锁定

**日期**：20260303  
**需求描述**：对 myanalyser 项目所有环境与依赖进行版本锁定，便于复现与协作。

## 需求澄清

- **目标**：锁定 Python 版本、pip 依赖、Docker 镜像版本，避免环境漂移导致结果不可复现。
- **方案**：采用方案一（最简实现）：`.python-version` + `requirements.txt`（顶层依赖）+ `requirements-lock.txt`（精确锁定）。

## 设计与实现

- **Python**：`myanalyser/.python-version` 锁定为 `3.12.12`，供 pyenv 自动读取。
- **pip**：
  - `requirements.txt`：顶层依赖及版本下限（akshare、pandas、numpy、PyMySQL、clickhouse-connect）
  - `requirements-lock.txt`：由 `pip freeze` 生成，含全部传递依赖精确版本
  - 复现环境推荐：`pip install -r requirements-lock.txt`
- **Docker**：`fund_db_infra/docker-compose.yml` 已锁定镜像 tag：`mysql:8.4`、`clickhouse/clickhouse-server:25.8`。

## 后续维护

- 新增依赖：在 `requirements.txt` 中添加，执行 `pip install <新包>` 后 `pip freeze > requirements-lock.txt` 更新锁定。
- 升级依赖：修改 `requirements.txt` 版本区间，安装后重新 `pip freeze > requirements-lock.txt`。
