# 20260303 看板可视化工具增强

## 需求描述（开发者提示）

gen_scoreboard_html.py 是目前的看板可视化工具。希望进行以下调整：

1. **明细表**：需要将 scored_result 这张表格的信息都纳入明细表。表头支持每列的筛选、排序。也支持勾选显示的列（默认全选）。

2. **风险-收益散点图**：用近一年年化收益率-近一年最大回撤绘制。

3. **综合得分分布图**：可以去掉。

4. **fund_etl 目录**：脚本额外传入 fund_etl 目录。看板增加一个所有基金的 fund_adjusted_nav 走势图。
   - 时间范围下拉：近1年、近3年
   - 数据选择区：默认按综合得分降序列出 scored_result 中的所有基金，默认选中综合得分 top10
   - 排序规则下拉：支持一键选择（按综合得分/风险控制/短期业绩/持有体验/长期业绩排序并改为选中该规则的 top10 基金）
   - 最近人事变动 toggle：选中后在图线上显示所有被选中基金的最近一次人事变更日期（若在所选时间范围内），默认不显示

## 实现摘要（AI 回复）

### 变更文件

- `myanalyser/tools/gen_scoreboard_html.py`：全面重构
- `myanalyser/tests/test_gen_scoreboard_html.py`：新增单测
- `myanalyser/docs/README.md`：更新 gen_scoreboard_html 用法说明

### 主要改动

1. **load_and_prepare**：返回完整行（所有列）及列名列表，不再只提取固定子集。

2. **明细表**：
   - 使用 scored_result 全部列
   - 表头支持筛选（每列输入框）、排序（点击表头）
   - 列可见性勾选（每列一个 checkbox，默认全选；顶栏「勾选显示列」支持全选/全不选）

3. **散点图**：改用「近1年最大回撤率」为 X 轴、「近1年年化收益率」为 Y 轴，优先匹配列名「近1年年化收益率」「近1年最大回撤率」。

4. **移除**：综合得分分布图（chartHist）。

5. **新增 -f/--fund-etl 参数**：
   - 从 fund_adjusted_nav_by_code 加载净值（净值日期、复权净值）
   - 从 fund_personnel_by_code 加载人事变动（取每只基金 max(公告日期)）
   - 增加「④ 基金复权净值走势图」卡片：
     - 时间范围：近1年 / 近3年
     - 基金多选：按当前排序规则列出有净值数据的基金，默认勾选 top10
     - 排序规则下拉 +「应用该规则 Top10」按钮
     - 「显示最近人事变动」复选框：在图上以虚线标记人事变动日期（限时间范围内）
   - 无 fund_etl 或净值数据为空时，不显示该卡片
