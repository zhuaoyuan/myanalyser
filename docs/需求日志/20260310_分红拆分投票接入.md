# 需求日志：分红拆分投票接入

日期：2026-03-10

## 背景与目标

- 分红/拆分单次爬取可能不稳定，需要在 step5 后进行多次投票校对。
- 保留原始 `fund_bonus_by_code` / `fund_split_by_code`，新增校对结果目录并用于后续流程。
- 校对结果需在 `data/common/revise/{YYYYMMDD}_{run_id}_revised` 留档。

## 需求摘要

- `fund_etl.py` 额外接收历史校对目录参数（仅一个）：`--bonus-split-revise-root`。
- step5 完成后调用 `tools/fund_bonus_split_vote.py`：
  - 使用 `purchase_csv` 中的基金清单作为校对对象；
  - 生成 `revised_fund_bonus_by_code`、`revised_fund_split_by_code`；
  - 在 `data/common/revise/{YYYYMMDD}_{run_id}_revised/fund_etl` 留档。
- `run_full_pipeline.sh`、`verify.sh` 使用 revised 目录做后续复权净值计算。

## 关键设计决策

- 校对结果不覆盖原始目录，新增 `revised_*` 目录供后续使用。
- 校对清单改为 `purchase_csv` 中的基金代码集合。
- 留档目录格式：`data/common/revise/{YYYYMMDD}_{run_id}_revised/fund_etl`。

## 验收命令（可执行）

```bash
python myanalyser/src/fund_etl.py \
  --run-id <RUN_ID> \
  --mode step5 \
  --purchase-csv <purchase_csv> \
  --bonus-split-revise-root myanalyser/data/common/revise/20260310_final
```

```bash
ls myanalyser/data/versions/<RUN_ID>/fund_etl/revised_fund_bonus_by_code
ls myanalyser/data/versions/<RUN_ID>/fund_etl/revised_fund_split_by_code
```

```bash
ls myanalyser/data/common/revise/20260310_<RUN_ID>_revised/fund_etl/fund_bonus_by_code
ls myanalyser/data/common/revise/20260310_<RUN_ID>_revised/fund_etl/fund_split_by_code
```
