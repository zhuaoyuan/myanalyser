# 20260311 pybroker 回测多过滤器链

## 需求背景
- 支持同时使用多种过滤条件缩小回测基金池。
- 一类：CSV 白名单（如 filtered_fund_candidates.csv）。
- 另一类：算出来的条件（如 max_funds 截断）。
- 采用方式 C：从模块导入注册表；主流程不感知 filter-csv 等额外输入，只支持多过滤器链式过滤。

## 设计与选型
- **过滤器抽象**：`FundFilter` 协议，`filter(candidates: set[str]) -> set[str]`。
- **过滤器实现**：每个过滤器读取自身环境变量，实现定制逻辑（如 FilteredCandidatesCsvFilter 解析 filtered_fund_candidates.csv）。
- **注册表**：`backtest/filters/registry.py`，`FUND_BACKTEST_FILTERS=filtered_candidates,max_funds` 指定链式顺序。
- **主流程**：`get_filter_chain()` 解析环境变量构建链，`apply_filter_chain(candidates, filters)` 依次应用。

## 实现要点
- 新增 `src/backtest/filters/`：base、filtered_candidates_csv、max_funds、registry。
- `load_fund_nav_data` 增加 `allowed_codes` 参数。
- `get_available_symbols(nav_dir)` 用于获取初始候选集。
- `pybroker_fund_backtest.py` 集成过滤器链，无新增 CLI 参数。
