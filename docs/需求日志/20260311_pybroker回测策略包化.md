# 20260311 pybroker回测策略包化

## 需求背景
- 基于 `pybroker_fund_demo.py` 抽象回测流程，在 `myanalyser/src/backtest/` 中新增回测框架与策略包机制。
- 策略包模式：单一 `--strategy` 选择一套筛选/评分/仓位策略组合。
- 重新实现现有 `filter_score` 策略逻辑（以低风险偏债为首个策略）。
- 输出汇总与明细报表到文件，并补充测试。
- 默认数据源使用 `finance-runs/run_20260310_191534/data`。

## 设计与风险讨论
- 策略接口拆分为 Filter/Score/Position，形成 StrategyBundle。
- 策略直接接收主流程内存数据结构，避免文件 IO 与旧接口适配。
- 回测按期调仓（非逐日/日内重算）。
- 报表需包含汇总指标与每期明细（含调仓前后持仓、换手率、现金比例等）。
- 风险：回测窗口不足导致指标不稳定、交易日对齐与缺失值、性能（评分计算）。

## 实现要点
- 新增 `myanalyser/src/backtest/` 模块，包含数据加载、指标计算、回测引擎、策略注册与实现。
- 新增 CLI：`myanalyser/tools/pybroker_fund_backtest.py`。
- 低风险偏债策略包实现（评分使用本地指标计算 + 综合得分）。
- 报表输出：`summary.csv` 与 `period_detail.csv`。
- 调整 review 提示：清仓逻辑、日期处理、性能优化、可配置 initial_cash、默认数据目录自动选择。
