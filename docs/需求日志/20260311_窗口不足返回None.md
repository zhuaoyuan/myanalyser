# 需求日志：近 N 年指标窗口不足时返回 None

- 日期：2026-03-11
- 范围：`src/fund_metrics_core.py`、`tests/test_backtest_pybroker_comprehensive.py`

## 1. 背景

`compute_low_risk_debt_metrics` 中「近 1 年」「近 3 年」指标使用 `safe_slice` 截取最近 N 个交易日。当回测期或评分数据不足对应窗口（如不足 729 天）时，`safe_slice` 会返回全部可用数据，但列名仍为「近 3 年」，容易造成误导——短样本被冠以「近 3 年」语义。

## 2. 方案选择

- **方案 A**：窗口不足时返回 `None`，语义清晰（本次采纳）
- **方案 B**：沿用现有行为，在展示层标注样本长度

## 3. 实现

### 3.1 fund_metrics_core.py

- 新增 `has_1y = len(prices) >= win_1y`、`has_3y = len(prices) >= win_3y` 判断
- `has_1y=False` 时：近 1 年相关指标（最大回撤、回撤修复天数、年化收益、卡玛、上涨星期比例、周涨跌幅标准差、夏普）返回 `None`
- `has_3y=False` 时：近 3 年相关指标（最大回撤、回撤修复天数、年化收益、卡玛、上涨月份比例、夏普）返回 `None`
- `最近一个月涨跌幅` 不受窗口约束，仍按可用数据计算

### 3.2 新增单测

- `test_metrics_window_insufficient_returns_none`：验证
  - 不足 1 年：近 1 年、近 3 年 均为 `None`
  - 不足 3 年但 ≥ 1 年：近 1 年有值，近 3 年为 `None`
  - ≥ 3 年：两者均有值
