# 需求日志：基金申购/赎回费率抓取脚本

日期：2026-03-13

## 背景与目标

- 从 `fund_purchase.csv` 读取基金编码，调用 akshare `fund_fee_em` 获取申购费率和赎回费率。
- 输出结构化 CSV，字段含：基金编码、申购状态、赎回状态、数据类型（申购费率/赎回费率）、费率、金额阶梯起点/终点、持仓期限阶梯起点/终点。
- 金额单位统一为万元，期限单位统一为天。
- 无费率数据的基金记录到异常日志，不写入主结果 CSV。

## 需求澄清

### 开发者提示（摘要）

1. 接收形如 `finance-runs/run_xxx/data/versions/xxx/fund_etl/fund_purchase.csv` 的参数。
2. 同一类型、同一阶梯有多项费率时（如「原费率」「天天基金优惠费率-活期宝购买」），取其中较小的。
3. 期限和金额阶梯为自然语言表述，需解析。
4. 若无「赎回费率」，降级到「赎回费率（前端）」。
5. 结果 CSV 增加申购状态、赎回状态，取自 purchase_csv；若申购状态≠开放申购 或 赎回状态≠开放赎回，无需查询费率，费率相关字段留空。

## 设计与风险

### 设计要点

- **自然语言解析**：适用金额（如「小于100万元」「大于等于500万元」）、适用期限（如「小于7天」「大于等于7天」「大于等于2年」）用正则解析为数值；年按 365 天换算。
- **费率取小**：申购费率多列（原费率、天天基金优惠费率-银行卡购买、天天基金优惠费率-活期宝购买）取百分比的数值最小值；固定费「每笔1000元」单独处理。
- **状态逻辑**：需同时满足「申购状态==开放申购」「赎回状态==开放赎回」（精确匹配）才查询；若 purchase_csv 缺失「申购状态」或「赎回状态」列，视为未知，全部查询（兼容旧版）。
- **请求节流**：`--delay` 参数控制每次 API 请求后休眠秒数，默认 0.3，降低限流风险。

### 输出 CSV 列

| 列名 | 说明 |
|------|------|
| 基金编码 | 6 位基金代码 |
| 申购状态 | 取自 purchase_csv |
| 赎回状态 | 取自 purchase_csv |
| 数据类型 | 申购费率 / 赎回费率 |
| 费率 | 百分比或「每笔1000元」 |
| 金额阶梯起点 | 万元 |
| 金额阶梯终点 | 万元 |
| 持仓期限阶梯起点 | 天 |
| 持仓期限阶梯终点 | 天 |

### 状态取值规范

- 申购状态需为「开放申购」、赎回状态需为「开放赎回」才查询费率（精确匹配，数据源为东方财富标准取值）。
- 「开放」「限大额」等视为非开放。
- 若两列均缺失，视为未知，全部查询（兼容旧版）。
