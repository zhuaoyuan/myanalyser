# 需求日志：基金规模变动抓取模块

日期：2026-03-13

## 背景与目标

- 封装基金规模变动数据抓取为正式模块，akshare 风格 API。
- 输入：基金编码；输出：包含 日期、期间申购（亿份）、期间赎回（亿份）、期末总份额（亿份）、期末净资产（亿元）、净资产变动率 的 pandas DataFrame。
- 数据来源：东方财富 FundArchivesDatas API，解析 `content` 内 HTML 表格。

## 设计与风险

### 设计要点

- **API 选择**：页面 `gmbd_{code}.html` 为 JS 动态渲染，直接请求仅返回 loading 占位。采用 FundArchivesDatas API 获取结构化数据，解析 `content` 内 HTML 表格。
- **接口风格**：`fund_gmbd_em(code: str) -> pd.DataFrame`，与 akshare 命名与返回值风格一致。
- **CLI**：`tools/fetch_fund_gmbd.py` 支持单/多基金编码、CSV 输入、输出 CSV，带 `--delay` 请求间隔。
