# 需求日志：基金持有人结构抓取模块

日期：2026-03-14

## 背景与目标

- 效仿 `fetch_fund_gmbd.py` 做基金持有人结构抓取。
- 数据来源：https://fundf10.eastmoney.com/cyrjg_{code}.html
- API：FundArchivesDatas.aspx，`type=cyrjg`
- 输出列：日期、机构持有比例、个人持有比例、内部持有比例、总份额（亿份）

## 设计确认

1. 列名：统一用 `日期`（与 gmbd 一致）
2. 比例格式：保留 `63.45%` 字符串
3. 模块命名：`fund_cyrjg.py`

## 实现摘要

### 变更文件

- `myanalyser/src/fund_cyrjg.py`（新增）：核心模块，`fund_cyrjg_em()`、`fetch_cyrjg_api()`、`_parse_cyrjg_from_html()`、`_parse_cyrjg_from_markdown()`、`_parse_cyrjg_from_content()`
- `myanalyser/tools/fetch_fund_cyrjg.py`（新增）：CLI，支持编码列表、CSV 输入、输出 CSV
- `myanalyser/tests/test_fund_cyrjg.py`（新增）：单测 22 个
- `myanalyser/docs/README.md`（更新）：核心脚本列表
- `myanalyser/docs/系统设计.md`（更新）：核心模块职责

### API 说明

- API 实际返回 **HTML 表格**（非调研阶段的 Markdown），解析逻辑优先 HTML，失败时回退 Markdown。
