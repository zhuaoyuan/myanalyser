# 需求日志：预备数据工作流

日期：2026-03-14

## 背景与目标

编写单独的「预备数据工作流」脚本，流程包括：

1. 传入指定开始日期 `date`
2. 获取全体基金购买 (x)（`fund_etl.run_step1_purchase`）
3. 根据 x 获取持有人比例全历史 (a)（`fetch_fund_cyrjg.py`）——若参数传入则直接使用
4. 根据 x 获取基金规模全历史 (b)（`fetch_fund_gmbd.py`）——若参数传入则增量查询
5. 根据 x 获取基金费率全历史 (c)（`fetch_fund_fee.py`）——若参数传入则增量查询
6. 根据 c 进行基金分类 (c.1)（`filter_fund_fee_by_holding.py`）
7. 根据 x 获取全体基金详情 (e)（`fund_etl.run_step2_overview`）——若参数传入则增量查询
8. 筛选：x + c.1(存在) + a(未出现机构持有>60%) + b(曾规模>2亿) + e(date前成立) → d.1

d.1 为最终结果文件，格式与 x 相同。

### 流程与参数

| 步骤 | 说明 | 可选参数 |
|------|------|----------|
| x | 基金购买 | `--purchase-csv` 跳过 step1 |
| a | 持有人比例 | `--cyrjg-csv` 直接使用 |
| b | 基金规模 | `--gmbd-csv` 增量查询 |
| c | 基金费率 | `--fee-csv` 增量查询 |
| c.1 | 费率分类 | - |
| e | 基金详情 | `--overview-csv` 增量查询 |
| d.1 | 筛选结果 | 输出至 `-o` 指定路径 |

### 筛选条件

- **c.1**：必须在费率分类结果中存在
- **a**：排除 date 至今出现过机构持有比例 > 60% 的基金
- **b**：仅保留 date 至今发生过规模 > 2 亿的基金
- **e**：仅保留 date 之前成立的基金（无法解析成立日期的排除）

## Code Review 调整（2026-03-14）

根据 review 意见对脚本进行修改：

| 优先级 | 问题 | 调整 |
|--------|------|------|
| Major | `_step_c_fee` 中 existing_csv 不存在时 to_fetch=None，codes 为空可能传入空 purchase 给 CLI | 统一 `to_fetch = sorted(codes) if codes else []`；`if not to_fetch` 时提前返回，无 existing 写空 DataFrame |
| Minor | `_apply_filters` a 段用 iterrows() 性能差 | 改用 `a_df["机构持有比例"].map(_parse_pct)` 向量化 + boolean 索引 |
| Minor | e 段筛选同样用 iterrows() | 改用 `e_df[col].map(_parse_date)` 向量化 |
| Minor | gmbd 合并可能产生重复行 | concat 后对 (基金代码, 日期) 执行 `drop_duplicates` |
| Minor | `_run_cli` cwd 与脚本路径依赖目录结构 | 使用 `(_MYANALYSER / "tools" / script).resolve()` 绝对路径，docstring 说明约定 |
| Minor | main 中 work_dir 在 None 时 resolve 语义 | 使用 `(args.work_dir or output_path.parent / "prep_work").resolve()` 统一处理 |
