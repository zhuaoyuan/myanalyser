# 20260315_宽存窄用_v2_phase0-2改造

日期：2026-03-15

## 背景与目标
围绕“宽存窄用 + 回测公平性”进行 v2 改造。Phase0 已完成宽存与基础工具；本次完成 Phase2：窗口化校验、L3 缓存、多 T 编排与 v2 L1-only pipeline。

## Phase0 已完成项（回溯记录）
- v2 预备数据宽存：`myanalyser/tools/v2/prep_data_workflow.py` 仅做全量抓取，不做筛选。
- 预备 eligible 基础离线工具：`myanalyser/src/v2/transforms/prep_eligible_from_cached.py`。
- 一阶段产物目录：`myanalyser/tmp/prep_work_v2`。

## Phase2 本次实现项
- Compare / Integrity 改为**按窗口重算并缓存**（避免全跨度污染与粒度不匹配）。
- 动态 prep eligible（a/b/e/c.1）**按窗口计算并缓存**，`multi_t_backtest.py` 中 `--prep-work-dir` 必填。
- Filter v2 支持 `--end-date`，规则 4/5 使用 `[start_date, end_date]` 判定。
- 多 T 编排器：`myanalyser/tools/v2/multi_t_backtest.py`。
- v2 run_full_pipeline：`myanalyser/tools/v2/run_full_pipeline.sh` **仅产出 L1**（ETL + adjusted_nav）。

## 新增/调整文件
- Compare（窗口化）：`myanalyser/src/v2/compare/compare_adjusted_nav_and_cum_return_window.py`
- Filter v2：`myanalyser/src/v2/filters/filter_funds_for_next_step.py`
- 动态 eligible（窗口化）：`myanalyser/src/v2/filters/prep_eligible_window.py`
- 多 T 编排器：`myanalyser/tools/v2/multi_t_backtest.py`
- v2 L1-only pipeline：`myanalyser/tools/v2/run_full_pipeline.sh`

## 缓存结构（L3）
`data/versions/{run_id}/cache/v2/`
- `compare/{ruleset_version}/{start}_{end}/summary.csv + details/`
- `integrity/{ruleset_version}/{start}_{end}/trade_day_integrity_summary_... + details_.../`
- `prep_eligible/{ruleset_version}/{start}_{end}/eligible_fund_candidates.csv`
- `filter/{ruleset_version}/{start}_{end}/filtered_fund_candidates.csv`
- `scoreboard/{ruleset_version}/{as_of_date}/{start}_{end}/fund_scoreboard_...csv`

## 关键行为变化
- Compare / Integrity 不再全跨度一次性产出，改为每个 T 窗口重算并缓存。
- Scoreboard 默认 `--skip-sinks` + `formal_only`，不落库。
- v2 全流程与旧版解耦，旧 `run_full_pipeline.sh` 保留。

## 验收要点与命令（示例）
```bash
# v2 L1-only pipeline
bash myanalyser/tools/v2/run_full_pipeline.sh @/absolute/path/to/fund_purchase.csv

# Compare 窗口重算
python myanalyser/src/v2/compare/compare_adjusted_nav_and_cum_return_window.py \
  --base-dir myanalyser/data/versions/<RUN_ID>/fund_etl \
  --start-date 2022-01-01 \
  --end-date 2025-12-31 \
  --output-dir myanalyser/data/versions/<RUN_ID>/cache/v2/compare/20260315_v1/2022-01-01_2025-12-31

# 动态 eligible（窗口）
python myanalyser/src/v2/filters/prep_eligible_window.py \
  --work-dir myanalyser/tmp/prep_work_v2 \
  --start-date 2022-01-01 \
  --end-date 2025-12-31 \
  --output myanalyser/data/versions/<RUN_ID>/cache/v2/prep_eligible/20260315_v1/2022-01-01_2025-12-31/eligible_fund_candidates.csv

# 多 T 编排
python myanalyser/tools/v2/multi_t_backtest.py \
  --run-id <RUN_ID> \
  --ruleset-version 20260315_v1 \
  --t-list 2024-01-15,2024-03-01 \
  --lookback-years 3 \
  --hold-days 42 \
  --trading-calendar-csv myanalyser/data/common/trade_dates.csv \
  --prep-work-dir myanalyser/tmp/prep_work_v2
```

## 影响与风险
- 多 T 首次运行计算量增大，依赖缓存降低重复成本。
- 远程收益率数据缺失导致窗口内公共日期不足时，会触发更严格过滤（安全优先口径）。
