## 三、开闭区间 检查

### 3.1 日期区间：普遍双闭 [start, end]

| 模块 | 条件 | 代码位置 |
|------|------|----------|
| load_trade_days | `>= start` and `<= end` | check_trade_day_data_integrity L47 |
| compare 明细筛选 | 期初 `>= start_date` and `<= end_date`；期末 `<= end_date` | filter_funds_for_next_step L67-71 |
| integrity 明细 | `>= start_date` and `<= end_date` | filter_funds_for_next_step L96 |
| compare 序列切片 | `>= start_ts` and `<= end_ts` | compare_adjusted_nav_and_cum_return_window L186-187 |
| prep_eligible a 规则 | `date <= end_ts`，`date >= cutoff` | prep_eligible_window L262, L274 |
| prep_eligible b 规则 | `date <= end_ts` | prep_eligible_window L283 |
| prep_eligible e 规则 | `_inc < start_ts`（成立早于窗口开始） | prep_eligible_window L253 |
| personnel 窗口 | `>= window_start` and `<= window_end` | prep_eligible_window L112 |

结论：**日期区间统一为双闭 [start, end]**，实现一致。

### 3.2 费率阶梯：左闭右开 [start, end) 的文档约定

文档 `fund_fee_空值成因分析_20260313.md` 约定：
- 金额阶梯、持仓期限阶梯：**左闭右开 [start, end)**，边界值归属下一档
- 无终点：`[start, ∞)`

`classify_fund_fee_by_holding.py` 仅识别「赎回费率为 0 的 [x,∞) 档」的起点 x 用于分类，**不直接对持仓天数做区间归属判定**，与文档约定无冲突。若后续有「按持仓天数选费率档」的逻辑，需严格按 [start, end) 实现。

### 3.3 回测持仓区间语义

`backtest_helpers.compute_end_extended_str`：
- `t_index = bisect_left(trading_days, as_of_date)`
- `end_index = t_index + hold_days`
- `return trading_days[end_index]`

含义：T 日买入，第 `hold_days` 个交易日后的那天卖出（不含 T 当日算第 0 天）。即持仓期为 **T 日到 T+hold_days 日**，共 `hold_days` 个完整交易日。实现与参数命名一致。

## 四、潜在问题与改进建议

### 4.1 lookback 口径（已落实）

- **现状**：`lookback-years` 已统一为 **1 年 = 243 交易日**（`backtest_helpers.compute_start_from_lookback`）。
- **文档**：`docs/参考/v2日期与区间协议约定.md`、`系统设计.md`、`项目通用约束.md` 已固化。

### 4.2 成立日、人事窗口的日期类型

- **现状**：成立+2年、end-1年 均用 `pd.DateOffset`，自然日。
- **评估**：与业务语义一致（成立满 2 年、近 1 年人事变动），可接受。

### 4.3 _resolve_trade_day 语义

```python
idx = bisect_right(trading_days, target) - 1
return trading_days[idx]
```

含义：若 target 非交易日，取其**前一交易日**。与「T 必须为交易日」的假设配合使用，逻辑正确。

### 4.4 t-step 的 end_idx 计算

```python
end_idx = bisect_right(trading_days, end_ts) - 1
indices = list(range(start_idx, end_idx + 1, int(t_step)))
```

`end_ts` 经 `_resolve_trade_day` 解析，已是交易日，`bisect_right - 1` 得到该日的索引，`range(..., end_idx + 1, ...)` 会包含该日。行为符合预期。
