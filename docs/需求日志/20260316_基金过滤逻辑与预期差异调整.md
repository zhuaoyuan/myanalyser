# 需求日志：基金过滤逻辑与预期差异调整

**日期**: 2026-03-16  
**需求描述**: prep_eligible_window 与 filter_funds_for_next_step 的规则与预期存在三处差异，按预期调整。

---

## 1. 差异与修改

### 差异 1：prep_eligible_window 规则 a（机构持仓）

| 项目 | 内容 |
|------|------|
| **现状** | 机构持仓仅在 [max(成立+2年, start_ts), end_ts] 内检查，[成立+2年, start_ts) 期间被忽略 |
| **预期** | 在 [成立+2年, 窗口 end_date] 内检查；若连续两次 > 60% 则排除 |
| **修改** | 不再先用 [start_ts, end_ts] 裁剪 cyrjg，对每只基金在 [成立+2年, end_date] 内检查连续两次 > 60% |

**实现**：`src/v2/filters/prep_eligible_window.py`
- `a_df` 仅按 `date <= end_ts` 过滤，不再按 `start_ts` 裁剪
- 对每只基金：`sub = grp[(grp[date_col] >= cutoff) & (grp[date_col] <= end_ts)]`，其中 `cutoff = 成立+2年`

### 差异 2：prep_eligible_window 规则 b（规模）

| 项目 | 内容 |
|------|------|
| **现状** | 窗口内任意一条规模 > 2 亿即保留 |
| **预期** | 仅使用 end_date 前最新一条规模；若该条 > 2 亿则保留 |
| **修改** | 对每只基金在 end_date 前取最新一条规模记录，用该条是否 > 2 亿判定 |

**实现**：`src/v2/filters/prep_eligible_window.py`
- `b_df` 仅按 `date <= end_ts` 过滤（不按 start_ts）
- `latest = b_df.loc[b_df.groupby("_code")["日期"].idxmax()]`
- `include_b = set(latest[latest["_scale"] > 2]["_code"].tolist())`

### 差异 3：filter_funds_for_next_step Compare/Integrity 区间

| 项目 | 内容 |
|------|------|
| **现状** | Compare、Integrity 检查区间为 [start_date, end_date]，与窗口一致 |
| **预期** | 检查区间为 [start_date, end_date + hold_days]（按交易日历），覆盖完整持仓周期 |
| **修改** | Compare、Integrity 的日期区间为 [start_date, end_date + hold_days] |

**实现**：
- `multi_t_backtest.py`：计算 `end_extended_str = trading_days[t_index + hold_days]`，compare/integrity 缓存与 filter 使用 `end_extended_str`
- `verify_filter_flow_report.py`：同样延伸 end_date 用于 compare、integrity、filter
- `filter_funds_for_next_step.py`：由调用方传入延伸后的 end_date，模块文档已更新

## 5. 补充变更：回测策略数据截断保证

**背景**：为避免策略实现依赖“自觉”使用 `as_of_date` 截断，回测引擎需要在调仓时统一保证策略可见数据不包含未来信息。

**改动**：
- 在 `run_backtest` 调仓流程中构造仅包含 `<= as_of_date` 的 `BacktestData` 视图，并将该视图传给 `filter_strategy` 与 `score_strategy`。
- 若 `BacktestData.long_df` 缺少 `date` 列，发出 `UserWarning` 并返回空 `long_df`，避免潜在 look-ahead。
- 截断后的 `long_df` 与 `by_symbol` 统一 `.copy()`，避免视图污染。
- `trading_dates` 生成逻辑简化为 `pd.to_datetime(...).normalize()`。

**实现**：`myanalyser/src/backtest/engine.py`
