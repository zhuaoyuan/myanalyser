## 二、预期范围（基于策略规则）

### 2.1 选基时的预期

- 最大回撤 ≥ -8%
- 年化 ≥ 5%
- 夏普 ≥ 0.5

### 2.2 持有期（126 天）的预期

持有期仅 126 个交易日，与选基时 3 年窗口不同，存在：

1. **窗口差异**：6 个月 vs 3 年，波动和噪声更大

| 最大回撤率 | ≥ -5% | ≥ -8% | < -8% |
| 胜率（正收益期占比） | ≥ 80% | ≥ 70% | < 70% |

## 五、未达预期部分的实际情况

### 5.1 时间聚类

未达预期期在时间上集中于：

1. **2016 Q3–Q4**：债市去杠杆、流动性收紧
2. **2021 Q4–2022 Q1**：债市调整、地产与信用风险
3. **2022 H2**：利率上行、债基回撤加大
4. **2023 H1**：利率波动、经济弱复苏

均为债市或信用环境较差的阶段，说明策略在极端环境下仍会出现负收益，但回撤未突破 -8%。

共同特征：选基前 3 年表现较好，但持有期（未来 126 天）遭遇债市调整，历史指标无法完全预测短期 regime 切换。

## 六、策略优化建议

### 6.1 短期 / 中等风险

1. **提高回撤门槛**  
   将最大回撤从 -8% 收紧至 -6% 或 -5%，可减少极端回撤，但会显著缩小候选池，可能牺牲收益。

2. **加入回撤修复天数约束**  
   参考固收型模板，增加「单次最长回撤修复天数 ≤ 90 天」等，过滤回撤恢复过慢的基金。

3. **提高夏普门槛**  
   将夏普从 0.5 提升至 0.8，筛选风险调整收益更好的基金，可能减少负收益期数量。

4. **缩短持有期**  
   将 hold-days 从 126 降至 63 或 84，提高再平衡频率，更及时应对 regime 切换，但会增加交易成本。

### 6.2 中期 / 需进一步验证

5. **加入市场环境信号**  
   在利率、信用利差等指标异常时降低仓位或提高筛选标准，需要额外数据和回测验证。

6. **分阶段打分权重**  
   熊市阶段提高回撤权重、牛市阶段提高收益权重，需要 regime 分类和更复杂的规则。

7. **多策略轮动**  
   在稳债策略之外引入货币、短债等防御策略，在债市明显不利时切换。

### 6.3 不建议轻易改动

- 硬约束已较为合理（-8% 回撤、5% 年化、0.5 夏普），过度收紧会明显减少可选基金
- 卡玛主目标与稳健型定位一致，不建议弱化
- 9 次负收益期主要集中在已知的债市调整阶段，有一定不可规避性
