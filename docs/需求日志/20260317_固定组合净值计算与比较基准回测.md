# 需求日志：固定组合净值计算与比较基准回测

**日期**: 2026-03-17  
**需求描述**: 实现固定基金组合净值计算基础脚本和上层批量工具，对比较基准.md 中 8 种被动组合（4 风格 × A/B）进行 2015.02.27~2026.03.13 的回测。

## 需求要点

1. **基础脚本** (`benchmark_portfolio_backtest.py`):
   - 接收参数：fund_etl 数据目录、起止日期、再平衡间隔交易日数、组合定义（`code:weight,...`）、完整性/比对阈值
   - 数据校验：复用 `check_trade_day_data_integrity` 和简化版 per-fund compare；无 cum_return 数据时降级为仅 integrity
   - 模拟逻辑：按权重建仓 → 日频净值跟踪 → 每 N 交易日再平衡
   - 产物格式与 chain 一致：equity_curve.csv、summary.csv、backtest_report.md、backtest_curves.html

2. **上层工具** (`run_benchmark_portfolios.py`):
   - 内置比较基准.md 中 8 种组合定义（硬编码，注释指向源文档）
   - 遍历各组合调用基础脚本（subprocess 隔离），生成 benchmark_summary.csv 汇总表
   - 默认起止日期：2015-02-27 ~ today()，再平衡间隔 243 交易日

3. **产物路径**: `artifacts/backtest_base/{run_id}/`（与 `backtest_multi` 同级）

## 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 数据源 | 强制传参 `--fund-etl-dir` | 避免硬编码 |
| compare 降级 | 无 cum_return 时跳过并提示 | ETF 基金可能无 cum_return 数据 |
| 模拟引擎 | 纯 pandas/numpy | 固定权重无需 PyBroker |
| BENCHMARKS 来源 | 硬编码 + 注释 | 从 Markdown 动态解析脆弱 |
| 批量隔离 | subprocess | 单组合崩溃不影响其他 |

## Review 修复

| 项 | 修复内容 |
|----|---------|
| 浮点零值判断 | `denom == 0` → `abs(denom) < 1e-9`；`100.0` 提取为 `_CUM_RETURN_BASE` |
| 近零收益率比对 | 改为对称相对误差 `abs(diff) / max(abs(a), abs(b))` |
| 错误信息 | ffill 前逐列检查全 NaN 基金，报出具体代码 |
| 防御性编程 | 建仓前检查首日净值 > 0 |
| DEFAULT_END | 硬编码 → `datetime.date.today().isoformat()` |
| 权重容差 | `0.01` → `1e-6` |
| 补充测试 | 新增 7 个用例覆盖 `_per_fund_compare` 和边界条件 |

## 用法

```bash
# 单组合运行
python myanalyser/tools/v2/benchmark_portfolio_backtest.py \
  --fund-etl-dir myanalyser/data/versions/RUN_ID/fund_etl \
  --start-date 2015-02-27 --end-date 2026-03-13 \
  --rebalance-interval 243 \
  --portfolio "161119:0.70,510300:0.30" \
  --output-dir myanalyser/artifacts/backtest_base/RUN_ID/稳健型_A

# 批量 8 组合运行
python myanalyser/tools/v2/run_benchmark_portfolios.py \
  --fund-etl-dir myanalyser/data/versions/RUN_ID/fund_etl
```
